# 🎓 رحلة الإنجليزية

تطبيق ويب في **ملف واحد** (`index.html`) بدون أي مكتبات.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً (أو احذف الملفات القديمة من المستودع الحالي).
2. ارفع `index.html` (و`README.md` إن أردت) **في جذر المستودع**.
3. Settings ← Pages ← Deploy from a branch ← `main` ← `/ (root)` ← Save.
4. الرابط: `https://USERNAME.github.io/اسم-المستودع/`

## التعديل
كل البيانات في أعلى وسم `<script>` داخل `index.html`: المستويات `LEVELS` والكورسات والأسئلة والبودكاست والكرتون.

## روابط الفيديوهات
- القناة: zAmericanEnglish. القوائم (PL) في أعلى `<script>` موثّقة من صفحات القناة نفسها.
- الدرس 1 وكورس الصوتيات (الجزء 1) روابطهما مباشرة. باقي الأيام تفتح القائمة الصحيحة.
- لجعل أي درس مباشراً: افتح القائمة، اضغط الدرس، انسخ المعرّف بعد `v=` وضعه في `LESSON_IDS`، مثلاً: `{ 1:"77IK9T45kiU", 2:"المعرّف" }`.

## تشغيل الدرس داخل التطبيق
اليوم N (من 1 إلى 25) يشغّل الحلقة N من قائمة المستوى الأول بمشغّل يوتيوب المدمج (`embed/videoseries?list=...&index=N-1`). يعتمد على أن ترتيب القائمة = ترتيب الحلقات. إن اختلف ترتيب حلقة، ضع معرّفها في `LESSON_IDS` فتتقدّم على الفهرس.
